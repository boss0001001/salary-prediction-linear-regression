# Salary Prediction using Linear Regression

This is a beginner Machine Learning project where I used Linear Regression to predict salary based on years of experience.

I built this project to understand how a basic regression model works, from loading the dataset to training the model and making predictions.

## About the Dataset

The dataset contains two main columns:

- YearsExperience
- Salary

The goal is to learn the relationship between years of experience and salary.

## What I Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## What I Did

In this project, I followed these basic steps:

1. Loaded the salary dataset.
2. Explored the data.
3. Selected YearsExperience as the input feature.
4. Used Salary as the target.
5. Split the data into training and testing sets.
6. Trained a Linear Regression model.
7. Checked the model's performance.
8. Used the trained model to predict a salary for a new input.

## Linear Regression Model

The model learned the following values:

- Intercept: 24848.20
- Slope: 9449.96

This means that according to the trained model, predicted salary increases by approximately 9449.96 for every additional year of experience.

## Model Evaluation

The model produced the following results:

| Metric | Value |
|---|---:|
| Mean Squared Error (MSE) | 31270951.72 |
| Root Mean Squared Error (RMSE) | 5592.04 |
